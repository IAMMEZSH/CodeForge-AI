Code inspector

                STATIC · NEVER EXECUTES
                

                
              

              

                
                
                

                  

                    
                    
                  

                  

                    
                    
                  

                  
                  
                

                

                  
                  IDLE
                

                
Every inspected file gets a detailed report: SHA-256/SHA-1/MD5, language and encoding, entropy, lines, classes, functions, imports, network clues, masked secrets, risk score and concrete indicators, plus JSON and Markdown files under workspace/reports/code-inspection/. Inspection only reads bytes — nothing is executed. After the report is written, the source files are re-hashed to prove they were not modified; the optional shred step overwrites and deletes only the quarantine copies created by this run, never the originals.
