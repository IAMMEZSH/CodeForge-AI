REQ-01

Content-type enforcement

Non-GET calls without application/json get 415. Blocks simple cross-origin form posts.

REQ-02

Origin = Host

A present Origin must match the Host origin or the call is rejected with 403.

LIM-03

8 MB request ceiling

Oversized bodies are rejected before parsing. Source code has a separate 200 KB cap.

NET-04

Loopback bind

Both listeners bind 127.0.0.1. Remote access requires your own authenticated TLS proxy.

INT-05

SHA-256 gates

Models and runtime archives are verified by the C17 helper before they are registered or executed.

INT-06

Safe extraction

ZIP and tar.gz entries are normalized; traversal and absolute paths abort the install.

PRC-07

Kill the whole tree

Windows Job Objects and POSIX process groups terminate children on timeout or shutdown.

PRV-08

No telemetry

No analytics, accounts, remote update or background upload. Download hosts are the only egress.

!

Honest boundaries

There is no OS sandbox and no API authentication token. Executed code runs with your privileges. Anyone who can reach the loopback port can execute code. Never expose 8765 directly to an untrusted network.
